# Final Design Essence

**UI/UX Design Guide · V1.0**  
**Essence: Playful Minimalism — Soft, Spatial & Interactive**

넉넉한 여백과 명확한 정보 위계를 바탕으로 유연한 카드 레이아웃, 부드러운 입체감, 경쾌한 인터랙션을 결합합니다.

기본 화면은 차분하게 유지합니다. 시각적인 재미는 콘텐츠 자체와 사용자가 선택·완료·확장·이동하는 순간에 집중합니다.

> **Calm by Default. Playful on Interaction.**

---

## 01. Visual Essence

### Airy Minimalism
넓은 여백과 절제된 시각 요소를 사용합니다. 화면을 채우기보다 콘텐츠 사이에 충분한 공간을 두어 정보의 우선순위를 자연스럽게 드러냅니다.

### Playful Composition
카드의 크기와 위치를 획일화하지 않습니다. 비대칭 그리드, 카드 중첩, 자유로운 오브젝트 배치를 활용해 미니멀한 화면에 리듬을 만듭니다.

### Soft Dimensionality
미세한 그림자, 반투명 소재, 레이어 중첩을 사용해 평면적인 UI에 깊이를 더합니다. 강한 입체 효과보다는 가볍고 부드러운 공간감을 지향합니다.

### Intuitive Flow
타임라인, 카드의 연결, 선택 상태 등을 이용해 정보의 흐름을 시각적으로 보여줍니다. 장식이 아니라 탐색과 상태 이해를 돕는 방향으로 사용합니다.

---

## 02. Visual Identity

| 요소 | 방향 |
|---|---|
| Style | Playful Minimalism |
| Layout | 넓은 여백 + 비대칭 카드 그리드 |
| Shape | 둥근 모서리 + 유기적인 오브젝트 |
| Depth | 미세한 그림자 + 중첩 + 반투명 레이어 |
| Image | 누끼 이미지 + 사진 + 3D 오브젝트 |
| Icon | 간결한 선형 아이콘 |
| Navigation | 필터 칩 + 타임라인 + 플로팅 버튼 |
| Interaction | 확장 + 슬라이드 + 드래그 + 상태 변화 |

콘텐츠를 단순히 사각형 안에 담긴 정보가 아니라 **독립적으로 만지고 움직일 수 있는 오브젝트**처럼 표현합니다.

다만 장식적인 오브젝트가 실제 정보나 주요 액션을 가리지 않아야 합니다.

---

## 03. Color System

### Neutral Foundation

화이트와 연회색 계열을 화면의 기본 환경으로 사용합니다.

배경과 기본 컴포넌트의 색상 대비를 강하게 만들기보다 여백, 경계, 명도 차이로 영역을 구분합니다.

### Expressive Accents

블루 계열은 주요 액션과 현재 선택 상태에 우선적으로 사용합니다.

옐로우, 핑크, 퍼플, 그린 등 부드러운 포인트 컬러는 카드와 콘텐츠 카테고리의 성격을 표현하는 데 활용합니다.

### Color Principle

**Neutral UI + Expressive Content**

UI 자체는 차분하게 유지하고 콘텐츠가 색을 갖도록 합니다.

색상만으로 상태를 전달하지 않습니다. 텍스트, 아이콘, 형태 변화 등을 함께 사용해 접근성을 확보합니다.

---

## 04. Typography

### Primary Typeface

**Pretendard**

한글과 영문이 혼용되는 서비스의 기본 서체입니다.

본문, 버튼, 내비게이션, 카드 등 UI 전반에 적용합니다.

**Weight**

Regular 400  
Medium 500  
SemiBold 600  
Bold 700

---

### Secondary Typeface

**Inter**

영문 중심의 제목, 숫자, 날짜, 시간 등에서 선택적으로 사용합니다.

Pretendard와 혼용하되 시각적인 장식을 위해 지나치게 많은 서체를 추가하지 않습니다.

---

### Type Scale

모바일 기준 권장값입니다.

| 유형 | 크기 / 행간 | 굵기 | 용도 |
|---|---:|---:|---|
| Display | 36 / 44px | 700 | 핵심 메시지 |
| H1 | 28 / 36px | 700 | 페이지 제목 |
| H2 | 24 / 32px | 600 | 주요 섹션 |
| H3 | 20 / 28px | 600 | 카드 제목 |
| Body L | 16 / 26px | 400 | 주요 본문 |
| Body M | 14 / 22px | 400 | 일반 본문 |
| Label | 13 / 18px | 500 | 버튼·칩 |
| Caption | 12 / 18px | 400 | 날짜·시간·보조 정보 |

### Typography Principle

큰 제목과 작은 보조 정보 사이에 확실한 대비를 둡니다.

제목은 짧게 유지하고 본문은 Regular~Medium을 기본으로 사용합니다. 정보 위계는 다양한 폰트를 사용하는 대신 크기, 굵기, 여백으로 표현합니다.

숫자나 날짜가 연속적으로 등장하는 영역에는 Tabular Numbers를 적용합니다.

텍스트와 배경의 대비는 WCAG AA 기준을 충족하도록 합니다.

---

## 05. Component & Layout

### Object-like Cards

카드는 핵심적인 시각 언어입니다.

단순한 정보 컨테이너보다 하나의 독립적인 오브젝트처럼 보이도록 구성합니다.

기본 Radius는 **16~28px** 범위에서 사용합니다.

카드의 중첩, 펼침, 이동은 콘텐츠 관계나 인터랙션을 표현할 때 사용합니다.

---

### Flexible Layout

정돈된 그리드를 기본으로 사용하되 모든 카드를 동일한 크기로 만들 필요는 없습니다.

콘텐츠 중요도와 성격에 따라 카드의 크기와 위치를 변화시킵니다.

비대칭 레이아웃을 사용하더라도 전체적인 여백과 정렬 기준은 유지합니다.

---

### Contextual Navigation

사용자의 현재 맥락에 필요한 탐색 요소를 우선적으로 제공합니다.

필터 칩, 주간 캘린더, 세로 타임라인, 플로팅 액션 버튼 등이 주요 패턴입니다.

모든 기능을 항상 노출하기보다 현재 화면에서 필요한 액션을 선별합니다.

---

## 06. Motion & Interaction

### Purposeful Motion

애니메이션은 장식이 아니라 **사용자의 행동과 화면 상태의 관계를 설명하는 수단**으로 사용합니다.

주요 패턴은 다음과 같습니다.

카드 확장·축소 / 슬라이드 / 드래그 / 선택 상태 변경 / 완료 피드백

| 인터랙션 | 권장 시간 |
|---|---:|
| 버튼 피드백 | 100~150ms |
| Card Hover / Press | 150~200ms |
| 카드 확장 / 축소 | 200~300ms |
| 화면 전환 | 250~350ms |

과도한 바운스, 반복 애니메이션, 느린 전환은 사용하지 않습니다.

`prefers-reduced-motion` 환경에서도 중요한 상태 변화를 인식할 수 있도록 설계합니다.

---

## 07. DO / DON'T

| DO | DON'T |
|---|---|
| 충분한 여백 확보 | 화면을 채우기 위한 정보 밀집 |
| 명확한 타이포그래피 위계 | 비슷한 크기와 굵기의 반복 |
| 일관된 모서리 반경 | 컴포넌트마다 임의의 Radius 사용 |
| 중요한 콘텐츠에 컬러 집중 | 모든 요소에 강한 컬러 사용 |
| 미세한 그림자로 레이어 구분 | 모든 카드에 강한 Shadow 적용 |
| 의미가 있는 카드 중첩 | 장식적인 중첩으로 정보 가리기 |
| 기능과 연결된 애니메이션 | 의미 없는 반복·바운스 효과 |
| 충분한 텍스트 대비 | 지나치게 연한 본문 텍스트 |
| 아이콘·텍스트를 포함한 상태 표현 | 색상만으로 상태 구분 |
| 선택적인 3D·Glass 효과 | 모든 컴포넌트에 입체 효과 적용 |

### 특히 피해야 할 것

Playful을 Colorful로 해석하지 않습니다.

Soft를 흐릿한 UI로 해석하지 않습니다.

Minimal을 정보 부족으로 해석하지 않습니다.

Spatial을 무조건적인 Glassmorphism이나 3D 효과로 해석하지 않습니다.

---

## 08. Design Principles

### 01. Clarity
장식보다 정보 이해를 우선합니다.

### 02. Breathing Room
정보 사이에 충분한 공간을 확보합니다.

### 03. Softness
둥근 형태, 부드러운 표면, 절제된 그림자를 사용합니다.

### 04. Playfulness
색상과 오브젝트, 인터랙션을 통해 작은 재미를 제공합니다.

### 05. Responsiveness
사용자의 행동에 즉각적인 시각 피드백을 제공합니다.

### 06. Consistency
카드, 색상, 상태 표현과 인터랙션 규칙을 일관되게 유지합니다.

---

## 09. Signature Experience

### Calm by Default. Playful on Interaction.

평상시 화면은 조용하고 정돈되어 있습니다.

사용자가 콘텐츠를 선택하거나 완료하고, 카드를 펼치거나 이동시키는 순간에는 색상과 움직임이 나타납니다.

즉, **미니멀리즘은 기본 상태를 담당하고 플레이풀한 요소는 콘텐츠와 상호작용을 담당합니다.**

이 두 요소가 항상 동시에 강하게 드러나는 것이 아니라 상황에 따라 역할을 나누는 것이 핵심입니다.

---

## 10. Final Design Checklist

디자인 검토 시 다음 항목을 확인합니다.

- [ ] 첫 화면에서 가장 중요한 정보가 바로 보이는가
- [ ] 충분한 여백이 확보되어 있는가
- [ ] 타이포그래피만으로 정보 위계를 이해할 수 있는가
- [ ] 카드가 단순한 박스의 반복처럼 보이지 않는가
- [ ] 포인트 컬러가 필요한 곳에만 사용되었는가
- [ ] 선택·완료·비활성 상태가 명확하게 구분되는가
- [ ] 그림자와 입체 효과가 과도하지 않은가
- [ ] 인터랙션이 사용자의 행동 결과를 설명하는가
- [ ] 장식 요소가 정보나 액션을 방해하지 않는가
- [ ] 접근성과 텍스트 가독성이 확보되어 있는가
- [ ] 전체 화면은 차분하지만 상호작용에는 시각적 재미가 있는가

---

## Design Statement

**Playful Minimalism**

타이포그래피와 여백으로 질서를 만들고, 색상과 입체감으로 개성을 표현합니다.

미니멀리즘은 화면의 기본 상태를 담당하고 플레이풀한 요소는 콘텐츠와 상호작용을 담당합니다.

> **정보를 읽기 편한 미니멀 UI와 만지고 싶은 오브젝트의 결합.**
