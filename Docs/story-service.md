# 유저스토리 — 냉장고 돋보기

> 출처: [prd.md](prd.md)

## 유저스토리

| # | 영역 | 유저스토리 | PRD 근거 |
|---|---|---|---|
| 1 | 재고 관리 | 개인 사용자가 포장지 촬영 또는 직접 입력으로 식재료의 이름·소비기한·구매일·가격·수량·보관 위치를 등록한다. | 1.1 |
| 2 | 재고 관리 | 개인 사용자가 재고를 타임라인 보기 또는 냉장고 배열 보기로 확인한다. | 1.2 |
| 3 | 재고 관리 | 개인 사용자가 식재료를 소비 완료·폐기로 처리하거나, 처리한 식재료를 다시 보관 중으로 되돌린다. | 1.2, 정책 1 |
| 4 | 재고 관리 | 개인 사용자가 식재료 등록 중이나 상세 화면에서 권장 보관 위치·온도·밀폐 방법을 확인한다. | 1.3 |
| 5 | 알림 | 개인 사용자가 소비기한이 임박(3일 이내)하거나 지난 식재료의 알림을 받고 재고를 확인한다. | 2.1, 정책 1·2 |
| 6 | 알림 | 개인 사용자가 냉장고 청소·음식물 쓰레기 배출·정기 구매 일정을 등록하고 알림을 받는다. | 2.2 |
| 7 | 알림 | 개인 사용자가 알림 유형별로 수신 여부와 시점을 설정한다. | 2번 수용 기준 3, 정책 2 |
| 8 | 냉장고 공간 | 개인 사용자가 실제 냉장고 구조에 맞춰 보관 구역을 추가·이름 변경·순서 변경·삭제한다. | 3.1 |
| 9 | 분석 | 개인 사용자가 기간별 구매·소비·폐기 금액과 폐기된 식재료 목록 및 폐기 사유를 확인한다. | 4.1, 4번 수용 기준 3 |
| 10 | 분석 | 개인 사용자가 보관 중인 재고의 탄수화물·단백질·지방 비율과 식재료별 영양소 기여도를 확인한다. | 4.2 |

## 이 서비스에서 어기면 안 되는 것

| # | 규칙 | PRD 근거 |
|---|---|---|
| 1 | 식품 안전성이나 변질 여부를 자동으로 판정하지 않는다. | 요약의 "안 할 것" |
| 2 | 외부 쇼핑몰 주문과 결제를 자동으로 실행하지 않는다. | 요약의 "안 할 것" |

## 결정 사항

- 공유 냉장고 구성원 관련 스토리는 이번 범위에서 제외한다.
- 폐기 사유는 필요하다. PRD의 식재료 데이터 필드에 폐기 사유 추가가 필요하다.
