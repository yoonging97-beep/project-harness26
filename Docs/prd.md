## 1. 프로젝트 개요
---
### 한 줄 정의
냉장고 식재료 관리 알림

### 제품 목표
바쁜 가구가 냉장고 속 식재료의 보관 위치와 소비기한을 빠르게 기록하고 제때 확인하도록 돕는다.
소비기한 알림과 재고·지출 분석을 통해 식재료 폐기와 중복 구매를 줄인다.
촬영 기반 입력과 간단한 상태 처리로 꾸준히 사용할 수 있는 관리 경험을 제공한다.

### 배경
식재료는 냉장고 안에 들어간 뒤 보관 위치와 소비기한을 쉽게 잊게 된다. 특히 장을 본 뒤 정보를 수기로 기록하는 일은 번거로워 관리가 끊기고, 그 결과 소비기한이 지난 재료의 폐기와 중복 구매가 반복된다. 냉장고 재고와 생활 일정을 한곳에서 간단히 관리할 수 있는 모바일 도구가 필요하다.

### 요약
- 냉장고 식재료 관리 알림은 바쁜 1~2인 가구와 식재료 관리를 맡은 가족 구성원이 냉장고 속 식재료를 촬영 또는 직접 입력으로 등록하고, 보관 위치·소비기한·영양소·보관 방법을 한곳에서 확인하도록 돕는 서비스다.
- 주요 사용자는 장을 본 뒤 식재료를 기록하고 소비기한을 챙기는 일을 반복하다 지친 직장인이다. 수기 기록의 번거로움 때문에 재료를 잊거나 중복 구매·폐기를 경험한다.
- 사용자 시나리오  
1. 장보기 후 등록: 포장지를 촬영한다 → 자동 추출된 이름·소비기한을 확인한다 → 냉장고 칸과 수량을 정한다 → 재고로 저장한다.  
2. 식사 전 재고 확인: 홈에서 임박 식재료를 확인한다 → 재고 목록 또는 냉장고 화면을 연다 → 우선 사용할 재료와 보관 위치를 확인한다 → 사용한 재료를 소비 완료로 처리한다.  
3. 주간 점검: 영양소 분석을 연다 → 재고의 탄수화물·단백질·지방 비율을 확인한다 → 식재료별 보관 방법을 확인한다 → 소비·폐기 지출을 보고 다음 구매를 조정한다.
- 만들 화면: 홈 대시보드, 재고 목록, 식재료 등록, 식재료 상세, 냉장고 레이아웃.
- 지켜야 할 것: 촬영 후 빠르게 등록할 수 있어야 한다. 소비기한·보관 방법·영양소 정보는 사용자가 확인·수정할 수 있어야 한다.  
안 할 것: 식품 안전성이나 변질 여부를 자동으로 판정하지 않는다. 외부 쇼핑몰 주문과 결제를 자동으로 실행하지 않는다.

### 사용자 문제
사용자는 냉장고 안에 무엇이 있는지, 언제까지 먹어야 하는지, 어디에 보관했는지를 한눈에 파악하기 어렵다. 수기로 모든 정보를 입력하는 과정이 번거로워 관리가 지속되지 않고, 그 결과 식재료 폐기와 중복 구매가 발생한다. 식재료의 영양 구성과 올바른 보관 방법도 확인하기 어려워 재료 활용과 식사 준비에 부담을 느낀다. 냉장고 청소·음식물 쓰레기 배출·정기 구매 같은 생활 일정도 식재료 관리와 분리되어 놓치기 쉽다.

### 해결 방안
사용자가 식재료를 직접 또는 카메라 촬영으로 등록하고, 보관 위치·구매일·소비기한·가격을 관리할 수 있는 모바일 중심 서비스를 제공한다. 소비기한 임박·경과, 과다 적재, 청소·배출·정기 구매 일정을 알림으로 안내하고, 냉장고 레이아웃과 소비·폐기·지출 기록을 시각화한다. 보관 중인 식재료의 탄수화물·단백질·지방과 주요 영양소 구성을 분석하고, 식재료별 권장 보관 위치·온도·밀폐 방법을 안내한다.

### 차별점
단순 유통기한 목록을 넘어 실제 냉장고 칸 구조에 맞춘 보관 위치 관리와 적재량 확인을 제공한다. OCR 기반 빠른 등록, 식재료별 보관 방법 안내, 재고 영양소 분석, 생활 관리 알림, 소비·폐기 비용 분석을 하나의 흐름으로 연결해 기록 부담과 음식물 낭비를 함께 줄인다.

### 타겟 사용자
주요 사용자는 1~2인 가구 또는 가족의 식재료 구매와 냉장고 관리를 맡는 바쁜 직장인이다. 이들은 장을 본 뒤 식재료를 자주 잊어버리거나, 유통기한이 지난 재료를 버리는 경험이 있으며, 복잡한 가계부나 수기 기록보다 빠른 촬영·알림 중심의 관리를 선호한다. 식재료를 활용해 균형 있는 식사를 준비하려 하지만 재고의 영양 구성과 보관 방법을 매번 찾아보기 어려운 사용자도 포함한다. 보조 사용자는 가족 구성원과 함께 냉장고 재고를 공유하고 싶은 가정의 구성원이다.

### 사용자 시나리오
사용자는 장을 본 뒤 식재료 포장지를 촬영해 이름과 소비기한을 자동으로 가져오고, 필요한 정보만 고쳐 냉장고 칸에 등록한다.
아침에 소비기한이 임박한 식재료 알림을 확인하고, 오늘 우선 먹을 재료와 냉장고 재고를 확인한 뒤 식사에 사용한 재료를 처리한다.
식사 준비 전에는 보관 중인 재료의 탄수화물·단백질·지방 비율과 주요 영양소를 확인하고, 특정 식재료의 권장 보관 위치와 밀폐 방법을 확인한다.
주말에는 냉장고 청소와 음식물 쓰레기 배출 알림을 받고, 한 달간 구매·소비·폐기한 금액을 확인해 구매 습관을 조정한다.

### 핵심 지표
주간 활성 사용자 중 식재료를 1건 이상 등록하거나 상태를 변경한 사용자 비율을 측정한다.
등록된 식재료 중 소비기한 전 소비 또는 폐기 상태로 처리된 비율을 측정한다.
소비기한 임박 알림의 열람률과 알림 이후 식재료 상태 변경률을 측정한다.
재고 영양소 분석과 보관 방법 안내의 조회율을 측정한다.
사용자별 월간 폐기 금액과 중복 구매 경험의 감소 추이를 측정한다.

### 리스크
OCR 인식 오류나 소비기한 정보 누락은 잘못된 알림으로 이어질 수 있으므로 사용자가 쉽게 확인·수정할 수 있어야 한다.
영양소와 보관 방법 정보는 식재료 종류·제품·상태에 따라 달라질 수 있으므로 정보 출처와 참고용 안내임을 명확히 표시해야 한다.
식재료 등록 과정이 길거나 알림이 과도하면 사용자가 기록과 알림을 끌 수 있다.
가족 공유, 카메라 이미지, 구매 금액 등 개인 정보는 접근 권한과 보관 범위를 명확히 관리해야 한다.
실제 식품의 안전성 판단은 제품 표시와 보관 상태에 따라 달라지므로 서비스 알림이 안전을 보장하지 않는다는 안내가 필요하다.

## 1. 식재료 재고 관리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 냉장고에 보관하는 식재료를 등록하고 현재 재고와 상태를 관리하는 영역이다. 식재료의 이름, 보관 위치, 구매 정보, 소비기한, 수량과 처리 상태를 다루며, 실제 주문·결제나 식품 안전성 판정은 포함하지 않는다.

**수용 기준:**
```
1. ○ 사용자는 식재료를 직접 입력하거나 카메라 촬영 기반 입력으로 등록할 수 있다.
2. ○ 사용자는 등록된 식재료의 정보와 보관 위치를 수정하거나 삭제할 수 있다.
3. ○ 사용자는 보관 중, 소비 완료, 폐기 상태별 식재료 목록을 확인할 수 있다.
```


### 1.1 식재료 빠른 등록
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 수기 입력 부담 때문에 식재료 관리가 지속되지 않는 사용자 문제를 줄이기 위해 빠른 등록 경로가 필요하다.

사용자가 직접 입력하거나 포장지 촬영으로 식재료를 새 재고로 등록하는 기능이다. 이름, 소비기한, 구매일, 가격, 수량, 보관 위치를 확인·수정한 뒤 저장하며, 제품 정보의 정확성을 보증하거나 외부 상품 정보를 구매하는 기능은 포함하지 않는다.

**성공 기준**: 주간 활성 사용자 중 식재료를 1건 이상 등록한 사용자 비율을 측정한다.

**개발 준비 슬롯**
- **선행조건**: - 사용자는 모바일 앱에서 식재료 등록 화면에 접근할 수 있다.
- **트리거**: - 사용자가 식재료 추가 버튼 또는 카메라 촬영 버튼을 선택한다.
- **동작**: - 사용자가 직접 정보를 입력하거나 포장지를 촬영한다.
  - 서비스는 촬영 이미지에서 식재료 정보를 추출해 입력 항목에 제안한다.
  - 사용자가 정보를 확인한 뒤 저장한다.
- **결과**: - 저장된 식재료가 보관 중 상태의 재고 목록에 추가된다.
  - 식재료 등록 분석 이벤트를 기록한다.
- **표시**: - 촬영 결과와 직접 입력 항목을 수정 가능한 등록 화면에 표시한다.
  - 저장 성공 시 등록 완료 메시지를 표시한다.
- **권한 & 접근**: - 개인 사용자는 자신의 냉장고에 식재료를 등록할 수 있다.
  - 공유 냉장고 구성원은 접근 권한이 있는 냉장고에만 식재료를 등록할 수 있다.
- **데이터**: - 식재료는 이름, 소비기한, 구매일, 가격, 수량, 보관 위치, 상태를 가진다.
  - 식재료 상태의 기본값은 보관 중이다.


### 1.2 식재료 목록과 상태 처리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 냉장고 안의 재고를 한눈에 파악하지 못해 식재료를 잊고 버리는 문제를 해결한다.

사용자가 보관 중인 식재료를 타임라인 보기 또는 냉장고 배열 보기로 확인하고, 소비 완료·폐기·수정·삭제로 처리하는 기능이다. 타임라인 보기는 소비기한과 상태를 중심으로 재료를 보여 주고, 냉장고 배열 보기는 보관 구역별 재료 위치를 보여 준다. 식재료의 현재 상태와 위치를 관리하며, 조리법 추천이나 자동 재고 감지는 포함하지 않는다.

**성공 기준**: 등록된 식재료 중 소비기한 전 소비 또는 폐기 상태로 처리된 비율을 측정한다.

**개발 준비 슬롯**
- **선행조건**: - 사용자의 냉장고에 등록된 식재료가 존재한다.
- **트리거**: - 사용자가 재고 목록 화면에 진입하거나 타임라인 보기와 냉장고 배열 보기 전환을 선택한다.
  - 사용자가 식재료 상세 화면에 진입한다.
- **동작**: - 서비스는 보관 중인 식재료와 상태를 조회한다.
  - 서비스는 타임라인 보기에서 소비기한과 상태를 기준으로 식재료를 표시한다.
  - 서비스는 냉장고 배열 보기에서 냉장칸, 냉동칸, 실온 보관 구역별 식재료를 표시한다.
  - 사용자는 식재료 정보를 수정하거나 소비 완료 또는 폐기 상태로 변경한다.
- **결과**: - 변경된 식재료 상태와 처리 시점을 저장한다.
  - 식재료 상태 변경 분석 이벤트를 기록한다.
- **표시**: - 재고 목록은 타임라인 보기와 냉장고 배열 보기 전환을 제공한다.
  - 타임라인 보기에서 식재료 이름, 소비기한, 현재 상태와 보관 위치를 표시한다.
  - 냉장고 배열 보기에서 냉장칸, 냉동칸, 실온 보관 구역별 식재료를 표시한다.
  - 재고가 없으면 식재료 등록을 안내하는 빈 화면을 표시한다.
- **권한 & 접근**: - 개인 사용자는 자신의 식재료를 조회하고 처리할 수 있다.
  - 공유 냉장고 구성원은 접근 권한이 있는 식재료만 처리할 수 있다.
- **데이터**: - 식재료 처리 기록은 처리 상태와 처리 시점을 가진다.


### 1.3 식재료 보관 방법 안내
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 사용자가 식재료별 적절한 보관 방법을 알면 신선도 저하와 불필요한 폐기를 줄일 수 있다.

사용자가 등록한 식재료에 맞는 권장 보관 위치·온도·밀폐 방법과 소비 전 확인 사항을 확인하는 기능이다. 식재료 상세와 등록 과정에서 안내를 제공하며, 실제 식품 안전성을 보증하거나 변질 여부를 자동 판정하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자가 식재료를 등록했거나 식재료 상세를 열었다.
- **트리거**: - 사용자가 식재료 등록 중 보관 방법을 확인하거나 식재료 상세에서 보관 안내를 선택한다.
- **동작**: - 서비스는 식재료의 이름 또는 분류에 맞는 권장 보관 방법을 조회한다.
  - 서비스는 보관 위치와 밀폐·분리 보관 등 필요한 안내를 제공한다.
- **결과**: - 사용자는 식재료별 권장 보관 방법을 확인하고 보관 위치를 선택할 수 있다.
  - 보관 방법 안내 조회 이벤트를 기록한다.
- **예외**: - 보관 방법을 찾을 수 없는 식재료에는 냉장·냉동 보관 전 확인이 필요하다는 일반 안내를 표시한다.
- **표시**: - 식재료 상세와 등록 화면에 권장 보관 위치, 권장 온도 범위, 밀폐 방법과 주의 사항을 표시한다.
  - 안내에는 실제 제품 표시와 상태를 우선 확인해야 한다는 문구를 표시한다.
- **권한 & 접근**: - 식재료를 조회할 수 있는 사용자는 해당 식재료의 보관 방법을 확인할 수 있다.
- **비즈니스 규칙**: - 권장 보관 방법은 식재료 등록 과정과 식재료 상세 화면에서 표시한다.
- **데이터**: - 보관 방법 정보는 식재료 식별값, 권장 보관 위치, 권장 온도 범위, 밀폐 방법, 주의 사항과 출처를 가진다.
  - 보관 방법 정보는 공공 식품 보관 가이드를 기준으로 관리한다.

## 2. 소비기한 및 생활 알림
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 소비기한과 생활 관리 일정을 놓치지 않도록 알림을 제공하는 영역이다. 식재료 소비기한, 냉장고 적재량, 청소·음식물 쓰레기 배출·정기 구매 일정을 대상으로 하며, 외부 쇼핑몰 주문 실행은 포함하지 않는다.

**수용 기준:**
```
1. ○ 소비기한이 임박하거나 지난 식재료에 대해 사용자에게 알림을 보낸다.
2. ○ 사용자는 생활 관리 일정과 정기 구매 알림을 등록하고 변경할 수 있다.
3. ○ 사용자는 알림 유형별 수신 여부와 시점을 설정할 수 있다.
```


### 2.1 소비기한 알림
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 사용자가 소비기한을 놓쳐 식재료를 폐기하는 문제를 줄이기 위해 사전 알림이 필요하다.

사용자가 소비기한이 임박했거나 지난 식재료를 알림으로 확인하는 기능이다. 알림을 통해 식재료 상세나 재고 목록으로 이동할 수 있으며, 식품의 안전성을 판정하거나 소비를 강제하지 않는다.

**성공 기준**: 소비기한 임박 알림의 열람률과 알림 이후 식재료 상태 변경률을 측정한다.

**개발 준비 슬롯**
- **선행조건**: - 식재료에 소비기한이 등록되어 있다.
  - 사용자가 해당 알림 수신을 허용했다.
- **트리거**: - 등록된 식재료의 소비기한이 알림 기준에 도달한다.
- **동작**: - 서비스는 소비기한 임박 또는 경과 상태를 확인한다.
  - 서비스는 대상 사용자에게 알림을 보낸다.
- **결과**: - 알림 발송 기록을 저장한다.
  - 알림 발송과 열람 분석 이벤트를 기록한다.
- **표시**: - 알림에는 식재료 이름, 소비기한 상태, 재고 확인 진입점을 표시한다.
- **권한 & 접근**: - 알림 수신을 허용한 사용자에게만 알림을 보낸다.
- **데이터**: - 알림 설정은 알림 유형, 수신 여부, 알림 시점을 가진다.
  - 알림 기록은 대상 식재료, 발송 시점, 열람 시점을 가진다.


### 2.2 생활 관리 일정 알림
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 식재료 관리와 연결된 생활 일정을 분리해 놓쳐 버리는 문제를 줄인다.

사용자가 냉장고 청소, 음식물 쓰레기 배출, 정기 구매 일정을 등록하고 알림을 받는 기능이다. 반복 일정과 일회성 일정을 관리하며, 외부 구매 서비스의 주문을 자동으로 실행하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자가 생활 관리 일정을 등록한다.
- **트리거**: - 등록된 일정의 알림 시점에 도달한다.
- **동작**: - 서비스는 일정 유형과 반복 주기를 저장한다.
  - 서비스는 일정 알림 시점에 사용자에게 알림을 보낸다.
- **결과**: - 일정 알림 발송 기록을 저장한다.
- **표시**: - 일정 목록에서 유형, 예정일, 반복 여부, 완료 상태를 표시한다.
- **권한 & 접근**: - 사용자는 자신의 생활 관리 일정을 생성하고 변경할 수 있다.
- **비즈니스 규칙**: - 지원하는 일정 유형은 냉장고 청소, 음식물 쓰레기 배출, 정기 구매이다.
- **데이터**: - 일정은 유형, 제목, 예정 시점, 반복 주기, 완료 상태를 가진다.

## 3. 냉장고 공간 구성
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

사용자가 자신의 냉장고 구조에 맞춰 보관 칸을 구성하고 식재료 위치를 확인하는 영역이다. 냉장·냉동·문칸 등 사용자가 정의한 보관 구역과 각 구역의 적재 상태를 다루며, 실제 냉장고 기기와의 연동은 포함하지 않는다.

**수용 기준:**
```
1. ○ 사용자는 냉장고 보관 구역을 추가, 이름 변경, 순서 변경, 삭제할 수 있다.
2. ○ 사용자는 식재료가 어느 보관 구역에 있는지 확인할 수 있다.
3. ○ 사용자는 보관 구역별 적재 상태를 확인할 수 있다.
```


### 3.1 냉장고 레이아웃 편집
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 식재료의 실제 보관 위치를 함께 기록해야 사용자가 냉장고 안에서 재료를 빠르게 찾을 수 있다.

사용자가 실제 냉장고 구조에 맞춰 냉장칸·냉동칸·실온 보관 구역을 만들고 순서를 조정하는 기능이다. 각 보관 구역의 이름과 구분을 관리해 식재료 위치를 실제 보관 환경에 맞게 기록하며, 스마트 냉장고 기기에서 구조를 자동으로 가져오는 기능은 포함하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자가 냉장고 설정 화면에 접근할 수 있다.
- **트리거**: - 사용자가 보관 구역 편집을 선택한다.
- **동작**: - 사용자는 냉장칸, 냉동칸, 실온 보관 구역을 추가, 이름 변경, 순서 변경, 삭제할 수 있다.
  - 사용자는 기본 보관 구역을 자신의 냉장고 구조에 맞게 편집할 수 있다.
- **결과**: - 변경된 보관 구역 구성이 저장된다.
- **표시**: - 보관 구역을 냉장칸, 냉동칸, 실온 보관 구역으로 나누어 사용자가 정한 순서로 표시한다.
  - 각 보관 구역에는 해당 구역에 배치된 식재료를 함께 표시한다.
- **권한 & 접근**: - 개인 사용자는 자신의 냉장고 보관 구역을 편집할 수 있다.
  - 공유 냉장고 구성원의 편집 권한은 공유 권한 정책을 따른다.
- **비즈니스 규칙**: - 새 냉장고에는 냉장칸, 냉동칸, 실온 보관 구역을 기본 보관 구역으로 제공한다.
- **데이터**: - 보관 구역은 이름, 순서, 구역 분류를 가진다.
  - 보관 구역 분류는 냉장, 냉동, 실온 보관으로 구분한다.
  - 식재료는 하나의 보관 구역을 참조할 수 있다.

## 4. 소비 및 지출 분석
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

사용자가 식재료 구매·소비·폐기 기록을 바탕으로 낭비와 지출 흐름을 확인하는 영역이다. 기간별 구매 금액, 소비 처리, 폐기 금액을 요약하며, 은행 계좌나 카드 거래 내역을 자동으로 불러오는 기능은 포함하지 않는다.

**수용 기준:**
```
1. ○ 사용자는 식재료를 소비 완료 또는 폐기로 처리할 수 있다.
2. ○ 사용자는 기간별 구매 금액, 소비 금액, 폐기 금액을 확인할 수 있다.
3. ○ 사용자는 폐기된 식재료와 폐기 사유를 목록으로 확인할 수 있다.
```


### 4.1 소비·폐기 지출 분석
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 사용자가 식재료 낭비와 지출 흐름을 돌아보고 구매 습관을 조정할 수 있게 한다.

사용자가 기간별 식재료 구매·소비·폐기 금액과 기록을 확인하는 기능이다. 등록된 가격과 상태 변경 기록을 바탕으로 요약을 제공하며, 카드 사용 내역을 자동으로 연동하거나 세무 처리를 하는 기능은 포함하지 않는다.

**성공 기준**: 사용자별 월간 폐기 금액의 감소 추이를 측정한다.

**개발 준비 슬롯**
- **선행조건**: - 식재료에 구매 가격 또는 처리 상태 기록이 존재한다.
- **트리거**: - 사용자가 소비 및 지출 분석 화면에 진입하고 기간을 선택한다.
- **동작**: - 서비스는 선택 기간의 구매·소비·폐기 식재료 기록을 집계한다.
- **결과**: - 사용자는 기간별 구매 금액, 소비 금액, 폐기 금액을 확인한다.
  - 분석 화면 조회 이벤트를 기록한다.
- **예외**: - 구매 가격이 없는 식재료는 금액 집계에서 제외한다.
- **표시**: - 기간별 금액 요약과 폐기 식재료 목록을 표시한다.
  - 집계할 기록이 없으면 기록 등록을 안내하는 빈 화면을 표시한다.
- **권한 & 접근**: - 사용자는 자신의 냉장고 분석 기록을 조회할 수 있다.
  - 공유 냉장고 구성원의 조회 범위는 공유 권한 정책을 따른다.
- **데이터**: - 분석 대상 기록은 구매 가격, 상태, 상태 변경 시점, 식재료 이름을 가진다.


### 4.2 재고 영양소 분석
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

**기능의 근거**: 사용자가 재고를 소비할 때 영양 구성을 함께 파악하면 식재료 활용과 구매 습관을 더 균형 있게 조정할 수 있다.

사용자가 냉장고에 보관 중인 식재료를 기준으로 탄수화물·단백질·지방과 주요 영양소의 예상 구성 비율을 확인하는 기능이다. 등록된 식재료명과 수량을 바탕으로 재고 전체와 식재료별 분석을 제공하며, 식단 처방이나 의학적 진단은 포함하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자의 냉장고에 분석 가능한 식재료가 등록되어 있다.
- **트리거**: - 사용자가 재고 영양소 분석 화면에 진입한다.
- **동작**: - 서비스는 보관 중인 식재료와 수량을 기준으로 영양소를 집계한다.
  - 서비스는 재고 전체와 식재료별 영양소 구성을 계산한다.
- **결과**: - 사용자는 탄수화물·단백질·지방의 비율과 주요 영양소 추정치를 확인한다.
  - 영양소 분석 화면 조회 이벤트를 기록한다.
- **표시**: - 화면에는 탄수화물·단백질·지방의 비율과 식재료별 영양소 기여도를 표시한다.
  - 분석 가능한 식재료가 없으면 식재료 등록을 안내하는 빈 화면을 표시한다.
- **권한 & 접근**: - 사용자는 자신이 접근할 수 있는 냉장고의 영양소 분석만 조회할 수 있다.
- **데이터**: - 영양소 정보는 식재료 식별값, 기준 수량, 열량, 탄수화물, 단백질, 지방과 주요 영양소 값을 가진다.

## 프로덕트 정책

### 1. 식재료 상태 및 소비기한 처리 규정

식재료 상태: - 식재료 상태는 보관 중, 소비 완료, 폐기로 구분한다.
- 보관 중 상태의 식재료만 현재 재고와 소비기한 알림 대상에 포함한다.

소비기한 표시: - 소비기한이 등록된 식재료는 현재 날짜와의 차이에 따라 임박 또는 경과 상태를 표시한다.
- 소비기한이 없는 식재료는 소비기한 알림 대상에서 제외한다.

임박 기준: - 소비기한이 3일 이내로 남은 식재료를 임박 상태로 표시한다.

처리 기록 변경: - 소비 완료 또는 폐기 처리된 식재료는 언제든 보관 중으로 되돌릴 수 있다.

식재료의 상태 변화와 소비기한 표시에 공통으로 적용하는 규정이다.

### 2. 알림 수신 규정

적용 대상: - 알림은 소비기한 임박·경과 식재료와 등록된 생활 관리 일정에 적용한다.
- 알림 수신을 허용한 사용자에게만 푸시 알림을 발송한다.

소비기한 경과 알림: - 소비기한 경과 알림은 식재료가 처리될 때까지 매일 발송한다.

수신 설정: - 사용자는 알림 유형별로 수신 여부를 변경할 수 있다.
- 사용자가 알림을 끄면 해당 유형의 새 알림을 발송하지 않는다.

소비기한과 생활 관리 일정에 적용하는 알림 수신 원칙을 정의한다.
