> 사용자가 값을 따로 정하지 않아도 작업이 진행되도록 쓰는 기본값이다.
> 사용자가 값을 정하면 그 값이 이 파일보다 우선한다. 바꾼 값은 이 파일에 반영한다.
>
> - 기준 문서: [design.md](design.md) (Playful Minimalism), 11. Moodboard
> - 적용 대상: 냉장고 돋보기 (모바일 사용 중심 웹앱/PWA)
> - 게이트 조건: [gates.md](gates.md)

## 1. Color

design.md에는 색 계열과 사용 원칙만 있고 색상값은 없다. **아래 HEX 값은 모두 🟠 임의값이다.**
색 계열·역할은 `D`를 따랐다. 대비는 WCAG 2.x 공식으로 계산했다.

### 1.1 Neutral (UI 기본 환경) — `D` 화이트·연회색 기반

| 토큰 | 값 | 용도 | 대비 |
|---|---|---|---|
| `bg` | 🟠 `#F4F5F7` | 화면 배경 (연회색) | – |
| `surface` | 🟠 `#FFFFFF` | 카드, 바텀시트 | – |
| `surface-sunken` | 🟠 `#EEF0F3` | 입력 필드, 비활성 칩, 폐기 상태 배경 | – |
| `border` | 🟠 `#E4E6EA` | 구분선, 카드 경계 | – |
| `text-primary` | 🟠 `#111418` | 제목, 본문 | surface 18.5 / bg 16.9 |
| `text-secondary` | 🟠 `#4B515A` | 보조 본문, 메타 정보 | surface 8.0 / bg 7.3 |
| `text-tertiary` | 🟠 `#6B717A` | 캡션, 플레이스홀더 | surface 4.9 / bg 4.5 |
| `ink` | 🟠 `#111418` | 검정 pill 버튼 배경 (`M` 01·06) | 흰 글자 18.5 |

### 1.2 Accent — `D` 블루는 주요 액션과 현재 선택 상태

## 2. Typography — `D`

| 항목 | 값 | 출처 |
|---|---|---|
| Primary | Pretendard (400 / 500 / 600 / 700) | `D` |
| Secondary | Inter — 영문 제목, 숫자, 날짜, 시간에만 | `D` |
| 숫자 | 날짜·수량·금액이 이어지는 영역에 `font-variant-numeric: tabular-nums` | `D` |
| 서체 수 | 위 2종 외 추가 금지 | `D` |
| Fallback | 🟠 `Pretendard, Inter, -apple-system, "Apple SD Gothic Neo", sans-serif` | 🟠 |

| 유형 | 크기 / 행간 | 굵기 | 용도 |
|---|---:|---:|---|
| Display | 36 / 44px | 700 | 핵심 메시지 |
| H1 | 28 / 36px | 700 | 페이지 제목 |
| H2 | 24 / 32px | 600 | 주요 섹션 |
| H3 | 20 / 28px | 600 | 카드 제목 |
| Body L | 16 / 26px | 400 | 주요 본문 |
| Body M | 14 / 22px | 400 | 일반 본문 |
| Label | 13 / 18px | 500 | 버튼·칩 |
| Caption | 12 / 18px | 400 | 날짜·시간·보조 정보 |

- 🟠 **최소 글자 크기 12px.** Type Scale의 가장 작은 값을 하한으로 삼았다.
- 🟠 **입력 필드 글자 16px 이상.** iOS Safari에서 16px 미만이면 입력 시 화면이 자동 확대된다.

## 6. Motion — `D`

| 인터랙션 | 시간 | 출처 |
|---|---:|---|
| 버튼 피드백 | 🟠 120ms (`D` 100~150ms) | `D` |
| Card Hover / Press | 🟠 180ms (`D` 150~200ms) | `D` |
| 카드 확장 / 축소 | 🟠 250ms (`D` 200~300ms) | `D` |
| 화면 전환 | 🟠 300ms (`D` 250~350ms) | `D` |
| Easing | 🟠 `cubic-bezier(0.2, 0, 0, 1)` | 🟠 |
| 금지 | 과도한 바운스, 반복 애니메이션, 느린 전환 | `D` |
| Reduced Motion | `prefers-reduced-motion`에서 이동 대신 투명도 전환, 상태 변화는 유지 | `D`, 🟠 방식 |

> 범위 안의 대표값을 하나씩 고른 것이 🟠 임의다. 범위 자체는 `D`다.

## 7. 임의값 요약 (🟠)

Claude가 정한 값만 모았다. 확정하거나 바꿀 값을 알려 주면 이 파일에 반영한다.

| # | 항목 | 임의값 | 이유 |
|---|---|---|---|
| 1 | 모든 HEX 색상값 | 1장 참고 | design.md에 색 계열만 있고 값이 없음 |
| 2 | content 색 ↔ 카테고리 매핑 | 냉장=그린, 냉동=핑크, 영양=퍼플, 일정=옐로우 | 매핑 기준 없음 |
| 3 | 상태 라벨 문구 | `D-n`, `기한 지남` | PRD에 표시 문구 없음 |
| 4 | 다크 모드 | 제공 안 함 | design.md 언급 없음 |
| 5 | 폰트 fallback, 최소 12px, 입력 16px | 2장 참고 | 수치 없음 / 모바일 웹 제약 |
| 6 | Radius 대표값 16·20·28, pill 999, inner 12 | 3장 참고 | 범위만 있음. inner 12는 범위 밖 |
| 7 | 그림자 값, 2단계 제한 | 3장 참고 | "미세한"만 있음 |
| 8 | 간격·여백·뷰포트·터치 영역 전체 | 4장 참고 | 수치 없음 |
| 9 | 이미지 없음 대체, 묶음 최대 3장, 아이콘 수치 | 5장 참고 | 기준 없음 |
| 10 | Motion 대표값과 Easing, Reduced Motion 방식 | 6장 참고 | 범위만 있음 |
