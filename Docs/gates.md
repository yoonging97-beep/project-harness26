# 게이트 조건 (gates.md)

> [story-work.md](story-work.md)의 게이트 G1~G4를 통과/실패로 판정할 수 있게 구체화한 조건이다.
> 값의 기준은 [default-design.md](default-design.md)이며, 사용자가 값을 바꾸면 바뀐 값으로 판정한다.

**판정 등급**

| 등급 | 의미 |
|---|---|
| **BLOCK** | 하나라도 걸리면 게이트 통과 불가. 실패 시 흐름으로 되돌린다. |
| **WARN** | 기록하고 통과할 수 있다. 다음 게이트 전에 사용자에게 보고한다. |

> 🟠 BLOCK/WARN 구분 자체가 Claude의 임의 분류다. 기준: 사용자 문서에 명시된 금지·규칙 = BLOCK, 주관 판단이 필요한 체크리스트 = WARN.

**근거 표시:** `D` design.md · `M` design.md 11. Moodboard · `P` prd.md · `S` story-service.md · `W` story-work.md · `DD` default-design.md · 🟠 Claude 임의 조건

## G1 — 요구사항·정책이 충분히 정의됐는가

실패 시: 질문 목록 작성 → B0

| ID | 조건 | 등급 | 근거 |
|---|---|---|---|
| G1-1 | 모든 요구사항이 `story-service.md`의 유저스토리 중 하나 이상에 연결된다. | BLOCK | `S`, `W` |
| G1-2 | 모든 유저스토리가 PRD 근거(섹션 번호)를 가진다. | BLOCK | `S` |
| G1-3 | PRD에 값이 없는 항목은 ① 질문 목록에 올라가 있거나 ② `default-*.md` 기본값으로 대체되고 🟠로 표시되어 있다. 둘 다 아니면 실패. | BLOCK | 사용자 요청 ("값을 안 정해도 진행") |
| G1-4 | 기존 정책과 충돌하는 요구사항이 질문 목록에 올라가 있다. | BLOCK | `W` G1 |
| G1-5 | 사용자 결정이 PRD와 다른 경우(예: 폐기 사유 필드 추가) 결정 사항으로 기록되어 있다. | WARN | `S` 결정 사항 |

## G3 — UI 디자인이 요구사항·화면설계와 일치하는가

실패 시: B2 (검토 결과·수정 요청 → 디자이너) → 재검토

### 일치

| ID | 조건 | 등급 | 근거 |
|---|---|---|---|
| G3-1 | 확정 화면설계서의 모든 화면·상태·빈 화면이 디자인에 있다. | BLOCK | `W` G3 |
| G3-2 | 화면설계서에 없는 기능·버튼이 추가되지 않았다. | BLOCK | `W` G3 |

### 색

| ID | 조건 | 등급 | 근거 |
|---|---|---|---|
| G3-3 | `default-design.md` 1장의 색 토큰 외 색상이 없다. | BLOCK | `DD` 1장 (🟠 값) |
| G3-4 | content 색(옐로우·핑크·퍼플·그린)이 버튼·내비게이션 등 UI 요소에 쓰이지 않는다. | BLOCK | `D` Neutral UI + Expressive Content |
| G3-5 | `primary` 블루는 주요 액션과 선택 상태에만 쓰인다. | BLOCK | `D` Expressive Accents |
| G3-6 | 본문 텍스트 대비 4.5:1 이상, 큰 텍스트(24px 이상 또는 18.66px 이상 굵게) 3:1 이상. | BLOCK | `D` WCAG AA |
| G3-7 | 상태가 색만으로 표현되지 않는다. (라벨 텍스트 + 아이콘 함께) | BLOCK | `D` Color Principle |

### 기능

| ID | 조건 | 등급 | 근거 |
|---|---|---|---|

| G4-2 | G2-5 ~ G2-16의 상태·예외가 구현에서 그대로 동작한다. | BLOCK | `W` G4 |

| G4-4 | 경과 알림은 처리될 때까지 매일 발송된다. | BLOCK | `P` 정책 2 |
